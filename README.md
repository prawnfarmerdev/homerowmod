# Homerow Mod

KMonad configurations for Homerow Mods, tailored for Emacs practice.

## Quick Start

1. Install [KMonad](https://github.com/kmonad/kmonad) for your OS.
2. Go to the `kmonad/` directory.
3. Run the setup script: `./setup-linux.sh` (Linux) or use `windows.kbd` (Windows)
4. For autostart on Linux: `./manage-service.sh enable-now`
5. Practice Emacs shortcuts with the homerow mods.

## Configuration Details

The homerow mods use the **GACS** order (GUI, Alt, Control, Shift) on the left hand, mirrored on the right hand. Tapping term is 200ms.

**Includes gaming layer**: Hold Caps Lock to toggle between homerow mods and gaming (normal home row keys).

**Note for sway users**: The sway configuration has been updated to remove `caps:ctrl_modifier` remap for compatibility.

See `kmonad/README.md` for full documentation and usage instructions.
